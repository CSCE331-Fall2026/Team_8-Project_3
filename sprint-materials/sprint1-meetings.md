## 11/9/2026 - Reflection Meeting
- Who Was Present: Tyler, Will, Arnav, Brandon, Vish

- Issues faced this sprint:

| Issue | Why it happened | How we will move forward |
| -------- | -------- | -------- |
| Confusion regarding Tech Stack | We were all pretty new to the tech stack, so there was a lot of initial confusion when getting started. | We will be taking time at the start of each sprint to familiarize ourselves with the stack and what needs to be done. |
| Deployment happened extremely last minute | Our initial deployment platform turned out to be impossible, so we had to change things last minute. The underlying issue is that we underestimated deployment. | We will be allocating more time for deployment. |

- Summary: Generally, we tried to challenge ourselves with using tools we hadn't really used before, which while was our intent, led to some difficulties. We also heavily underestimated what issues might occur during deployment, so we had to rush to deploy last minute, facing the issues that did occur.
